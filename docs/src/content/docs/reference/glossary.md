---
title: Glossary
description: Stable AeroCMS terms used across conceptual, manager, developer, and API documentation.
---

**Aero composition**

The default semantic `HtmlPageContent` page model and visual editor, renderer ID `aero.composition`.

**Audience**

Manifest trust class: public, manager/internal, or security-sensitive/excluded.

**Content item**

A site/culture-scoped instance of a content type with draft/published state and optional parent.

**Content query**

A bounded, validated request that materializes published or trusted-preview content into immutable renderer data.

**Content type**

A site-owned definition of cardinality, flat/hierarchical structure, fields, validation, rendering, and search behavior.

**Culture variant**

A localized page, post, doc, navigation/footer, or content item related to—but published independently from—another culture.

**Document (AeroCMS docs)**

A hierarchical documentation-space section. This is distinct from a generic Sable document.

**Git submodule**

An external repository linked into the AeroCMS checkout. Git-submodule documentation is excluded from this corpus.

**Manager**

The authenticated administration experience and its `/manager` and `/api/v1/admin` boundaries.

**Module**

An AeroCMS feature registered in the source-generated module catalog. Not synonymous with Git submodule.

**Published snapshot**

The exact public version of a page/content record. Draft changes do not alter it until publishing succeeds.

**Sable**

The active AeroCMS document/query persistence boundary over SurrealDB.

**Selected site**

The manager site ID stored in `AeroCms.SiteId`. The cookie is selection state, not authorization; sensitive operations must revalidate site existence and the user's assignment.

**Site**

The host, content, culture, theme, and authorization scope inside a tenant.

**Snowflake ID**

A 64-bit `long` generated by `Snowflake.NewId()`. JSON, JavaScript, Scriban, SharpTS, and MCP surfaces use decimal strings where precision requires it.

**Tenant**

The ownership boundary containing one or more sites.
