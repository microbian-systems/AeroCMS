# AeroCMS public API reference

This reference covers the intentionally supported authoring, composition, host-bootstrap, and extension contracts. It excludes application internals, feature-module implementations other than the explicitly documented experimental Commerce surface, generated code, legacy Marten reference code, and every Git submodule.

Start with the [extension guide](/developers/extensions/) for the supported module boundary, the [page-rendering guide](/guides/pages-and-rendering/) for composition contracts, or the [public content query guide](/guides/public-query-api/) for the HTTP integration surface.

The conceptual [Commerce guide](../docs/src/content/docs/guides/commerce.md) covers the current catalog, storefront, basket/order, payment/subscription, manager, page-editor, A2A, security, and operations boundaries. The Commerce module's public .NET types are included in this API reference while the feature remains experimental.

> AeroCMS is alpha software. Public contracts can still change before a stable release.
